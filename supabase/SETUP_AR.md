# إعداد قاعدة بيانات Game Box

## ربط المشروع

ملف `supabase-config.js` يحتوي عنوان مشروع Supabase والمفتاح العام المخصص للمتصفح. لا تضع مفتاح `service_role` أو كلمة مرور قاعدة البيانات في ملفات الموقع.

## تفعيل الزوار بدون شاشة تسجيل دخول

1. افتح لوحة مشروع Game Box في Supabase.
2. من **Authentication** افتح **Sign In / Providers**.
3. فعّل **Allow anonymous sign-ins** ثم اضغط **Save changes**.

الموقع ينشئ جلسة زائر تلقائيًا عند أول ضغط على زر تنزيل. لا تظهر للزائر شاشة تسجيل أو كلمة مرور.

## إنشاء الجداول والإجراءات

1. افتح **SQL Editor** من القائمة الجانبية.
2. أنشئ استعلامًا جديدًا.
3. انسخ محتوى `supabase/schema.sql` كاملًا والصقه.
4. اضغط **Run** مرة واحدة.

الاستعلام ينشئ كتالوج الألعاب وإحصاءات ضغطات التنزيل. يستطيع الزائر احتساب اللعبة مرة واحدة في اليوم، وتُرجع قاعدة البيانات أعلى ثلاث ألعاب ترتيبًا.

## نشر التعديلات

احفظ الملفات، ثم اعمل Commit وPush من GitHub Desktop. بعد انتهاء تحديث GitHub Pages، افتح الموقع من رابط HTTPS واضغط أزرار التنزيل لتجربة تسجيل الإحصاءات.

## ملاحظات

- الموقع لا يعرض تسجيل دخول أو إنشاء حساب للزوار.
- أعلى الألعاب في الصفحة الرئيسية تعتمد على الإحصاءات المسجلة في قاعدة البيانات. قبل تسجيل إحصاءات كافية، تظهر اختيارات افتراضية.
- أزرار التنزيل تفتح صفحات الناشرين الرسمية؛ الموقع لا يستضيف ملفات الألعاب.
