# ربط قاعدة البيانات وتسجيل الدخول

## 1. إنشاء مشروع Supabase

افتح [Supabase](https://supabase.com/dashboard)، أنشئ مشروعًا جديدًا، واختر كلمة مرور لقاعدة البيانات واحفظها عندك. **لا ترسل كلمة المرور أو أي مفتاح `service_role` لأي شخص.**

## 2. إنشاء جداول وإجراءات الموقع

من لوحة المشروع افتح **SQL Editor**، ثم افتح الملف `supabase/schema.sql` من هذا المشروع، وانسخ محتواه إلى محرر SQL واضغط **Run**. هذا ينشئ حسابات التنزيلات المشتركة ويضيف الألعاب الخمسين.

## 3. تشغيل تسجيل الدخول بالبريد

من لوحة Supabase افتح **Authentication → Providers → Email** واترك تسجيل البريد وكلمة المرور مفعّلًا. تأكيد البريد الإلكتروني مناسب للموقع. من **Authentication → URL Configuration** أضف رابط موقع GitHub Pages إلى عناوين التحويل المسموحة، مثل:

`https://nour0112736754-cyber.github.io/Game-Box-site/**`

واجعل رابط الموقع الأساسي هو رابط GitHub Pages نفسه.

## 4. ربط ملفات الموقع بالمشروع

من **Project Settings → API** انسخ **Project URL** و**Publishable key** (أو `anon` key القديمة)، ثم ضع القيمتين في `supabase-config.js` مكان `YOUR_PROJECT_ID` و`YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY`.

المفتاح العام مسموح في واجهة المتصفح مع حماية الجداول بـ RLS. لا تضع `service_role` أو كلمة مرور قاعدة البيانات في ملف الموقع.

## 5. نشر التغييرات

احفظ الملفات، ثم اعمل Commit وPush من GitHub Desktop. بعد اكتمال تحديث GitHub Pages، افتح:

`https://nour0112736754-cyber.github.io/Game-Box-site/login.html`

أنشئ حسابًا، أكّد البريد إذا طُلب، وسجّل الدخول. تنزيل اللعبة يظل متاحًا للجميع، لكن ضغطة زر التنزيل تدخل في الترتيب المشترك فقط للمستخدم المسجّل، وبحد أقصى مرة واحدة لكل لعبة لكل حساب في اليوم. الموقع يسجل **ضغطة الزر** ولا يستطيع معرفة اكتمال تنزيل الملف عند الناشر.

## ملاحظة تريلر الخلفية

اختبار فيديو YouTube من ملف `file://` قد يظهر خطأ 153 لأن المشغّل يحتاج عنوان HTTP Referer. اختبر الموقع عبر GitHub Pages أو خادم محلي `http://localhost`؛ صفحة GitHub Pages سترسل عنوان الموقع إلى المشغّل.
