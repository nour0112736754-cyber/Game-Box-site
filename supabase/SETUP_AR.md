# إعداد قاعدة بيانات Game Box

## ربط المشروع

ملف `supabase-config.js` يحتوي رابط Supabase والمفتاح العام المخصص للمتصفح. لا تضع مفتاح `service_role` أو كلمة مرور قاعدة البيانات في ملفات الموقع.

## تفعيل إحصائيات التنزيل بدون جلسات زوار

لم يعد الموقع ينشئ مستخدمًا أو جلسة مجهولة. عند الضغط على زر التنزيل، يسجل قاعدة البيانات نقرة مجمعة فقط، ثم يفتح الموقع صفحة الناشر الرسمية. النقر لا يثبت أن التنزيل اكتمل.

## تحديث قاعدة البيانات

1. افتح مشروع Game Box في Supabase ثم **SQL Editor**.
2. افتح استعلامًا جديدًا.
3. انسخ محتوى `supabase/schema.sql` كاملًا والصقه.
4. اضغط **Run** وانتظر رسالة نجاح.

الاستعلام يحدّث مخطط الإحصائيات القديم مع الاحتفاظ بالنقرات المسجلة، ويمنح الموقع صلاحية تسجيل النقرات وقراءة النتائج المجمعة. لا يحتاج الموقع إلى تفعيل **Allow anonymous sign-ins**.

## لوحة الإحصائيات

تسجيل الدخول بالبريد مخصص للوحة التحكم فقط؛ صفحات الموقع العامة لا تطلب تسجيل الدخول. بعد تشغيل `schema.sql`، أضف بريد المشرف في Supabase SQL Editor مباشرةً (ولا تضعه في ملفات الموقع أو GitHub):

```sql
insert into public.dashboard_admins (email)
values (lower('ضع-بريد-المشرف-هنا'))
on conflict (email) do nothing;
```

بعد نشر ملفات الموقع، افتح `dashboard.html`. أرسل رابط الدخول إلى البريد المضاف أعلاه وافتحه من صندوق البريد. تعرض اللوحة إجمالي النقرات، نقرات اليوم وآخر 7 أيام، عدد الألعاب ذات النشاط، ترتيب الألعاب، ورسمًا للنقرات اليومية.

## نشر التعديلات

احفظ الملفات ثم اعمل Commit وPush من GitHub Desktop. بعد انتهاء تحديث GitHub Pages، افتح لوحة الإحصائيات. إذا ظهر تنبيه أن الاستعلامات غير متاحة، شغّل `supabase/schema.sql` في SQL Editor كما في الخطوات أعلاه.

## الخصوصية وحدود الإحصائيات

- لا تُجمع أسماء الزوار أو بريدهم أو معرّفات جلسات Auth.
- تُسجل نقرات أزرار التنزيل فقط، ولا تُسجل نتيجة التنزيل الفعلية.
- صفحة الإحصائيات محمية بمقارنة البريد المسجل في الجلسة مع قائمة المشرفين داخل قاعدة البيانات. قراءة الجدول ودوال الإحصاءات محجوبة عن الزوار.
- لا تعرض اللوحة بيانات تعريفية عن زوار الموقع.
